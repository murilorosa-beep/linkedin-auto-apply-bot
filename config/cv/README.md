# Currículo em PDF (Resume)

Coloque aqui o seu currículo no formato PDF com o nome:
`resume.pdf`

Dicas para vagas internacionais:
1. O currículo deve estar 100% em **Inglês**.
2. Formato ATS-friendly (texto selecionável, sem colunas complexas ou tabelas pesadas).
3. Inclua seus links para LinkedIn e GitHub logo no cabeçalho.
